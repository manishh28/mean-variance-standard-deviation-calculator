# Mean-Variance-Standard Deviation Calculator

Solution for the freeCodeCamp Data Analysis with Python project.

`calculate()` accepts a list of nine numbers, creates a 3 x 3 NumPy matrix, and returns the mean, variance, standard deviation, maximum, minimum, and sum for each axis and for the flattened matrix.

## Run

```bash
pip install -r requirements.txt
python main.py
python -m unittest test_module.py
```
